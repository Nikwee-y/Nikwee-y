## Selected Projects

### [Wazuh Home Lab](https://github.com/Nikwee-y/Wazuh-Home-Lab)
A documented home SOC lab exploring endpoint monitoring, centralized log collection, alert analysis, and investigation workflows. Includes architecture, event-flow documentation, validation guidance, and a roadmap for future integrations.

### IPsecGuard-AI · SIH26160
An AI-assisted IPsec VPN analysis and security-assessment project concept focused on extracting configuration evidence, normalizing security settings, and evaluating them against policy.

### RootVerse Cyber News
A Python automation project for collecting cybersecurity news and publishing curated updates to a Discord community.

### Hash Identifier
A learning project that examines hash-string characteristics to suggest possible hash formats, while recognizing that a string's format alone cannot prove the hash algorithm.
